# Security Policy

## Supported versions

Only the latest release of `brewpage-mcp` (npm package, container image and the remote endpoint `https://brewpage.app/mcp`) receives security fixes. Upgrade to the latest version before reporting.

## Reporting a vulnerability

Email [info@brewpage.app](mailto:info@brewpage.app) with a description, affected version and steps to reproduce. Do not open a public issue for a vulnerability.

You get an acknowledgement within 3 business days and a status update within 10 business days. Confirmed issues are fixed in a new release, and the reporter is credited unless they prefer otherwise.
