BrewPage MCP

Free instant hosting for HTML, multi-file sites, KV, JSON, and files -- exposed as a Model Context Protocol server so AI agents can publish without leaving the conversation.

What is BrewPage

BrewPage is a free instant hosting platform for HTML pages, multi-file static sites, KV entries, JSON documents, and binary files. One POST returns a stable HTTPS short URL with no accounts and no API keys. Every resource carries an owner token for in-place updates, deletes, and cross-session listing.

BrewPage ships an LLM-friendly surface: /llms.txt, /llms-full.txt, an OpenAPI spec, and the brewpage-mcp server so Claude, Codex, Gemini, Cursor, and Cline can publish and manage content directly.

MCP tools (six)

ToolPurpose
publish_htmlPublish HTML or Markdown; returns public URL + owner token.
publish_fileUpload a file by fetching it from a URL.
publish_sitePublish a single-page or multi-file static HTML site.
delete_resourceDelete an HTML page, KV entry, JSON collection, or file using the owner token.
get_pageFetch the content of a published HTML page by namespace + ID.
get_statsPlatform-wide usage statistics (pages, files, storage, daily totals).

Install

The server is published to npm as brewpage-mcp and pinned to 1.4.0. Add this snippet to your client's MCP configuration (Claude Desktop, Codex CLI, Cursor, Cline): 

{
  "mcpServers": {
    "brewpage": {
      "command": "npx",
      "args": ["-y", "brewpage-mcp@1.4.0"]
    }
  }
}
