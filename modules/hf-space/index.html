BrewPage MCP

Free instant hosting for HTML, multi-file sites, KV, JSON, and files -- exposed as a Model Context Protocol server so AI agents can publish without leaving the conversation.

What is BrewPage

BrewPage hosts HTML pages, multi-file static sites, KV entries, JSON documents, and binary files. Publish immediately or connect an account for account-owned publications. Share the returned HTTPS reader link and keep any newly issued anonymous owner token private.

BrewPage ships an LLM-friendly surface: /llms.txt, /llms-full.txt, an OpenAPI spec, and the brewpage-mcp server so Claude, Codex, Gemini, Cursor, and Cline can publish and manage content directly.

MCP tools (six of 13)

ToolPurpose
publishPublish inline content, a complete site bundle, a public file URL, JSON or KV.
update_publicationReplace existing content. For a site, send all retained files and the intended entry.
read_publicationRead published content or an authorized owner view.
delete_publicationDelete an owned publication or one KV key.
read_page_dataRead visitor data settings, entries, totals or uploads as an owner.
get_guideRead a workflow for publishing, Page data, templates or accounts.

Version 3.2.1 advertises the compact catalog. Cached calls from earlier versions remain supported.

Install

Remote (no install): add https://brewpage.app/mcp as a remote MCP server (Streamable HTTP, anonymous access or optional account connection): a custom connector in Claude.ai and Claude Desktop, a custom MCP server in ChatGPT, or any Streamable HTTP client. Setup for every AI tool: brewpage.app/integrations.

Local package, for clients that only start local servers (needs Node.js). Add this snippet to the client's MCP configuration (Claude Desktop, Codex CLI, Cursor, Cline): 

{
  "mcpServers": {
    "brewpage": {
      "command": "npx",
      "args": ["-y", "brewpage-mcp@3.2.1"]
    }
  }
}
